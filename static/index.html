What this demo proves

Automatic UE discovery

Each laptop agent reports its live uesimtun interfaces. The web can manage multiple UE hosts without hard-coding one NUC.

Slice-aware execution

172.16.45/46/47/49 addresses are mapped to eMBB, URLLC, mMTC, and MEC independently of interface numbering.

Real 5G data path

The controller orchestrates over the LAN, while the actual robot request is bound to the selected UE tunnel and traverses the 5G user plane.
